# 交易概览首轮交付（issue #29，Phase 1–3）

## 现状与边界

网页入口为 `web/index.html`，`app.js` 负责快照、表格和刷新；`ui.js` 提供共享控件，`flow.js` / `activity.js` 负责执行遥测，`settings.js` 和 `schedule.js` 管理表单。没有 package 依赖、前端打包器或前端路由服务。`resources.qrc` 把网页嵌入程序，`src/app/server.cpp` 按白名单提供静态资源；Windows 使用 Qt WebEngine，其他系统使用浏览器。审查了 README、架构文档、资源注册、服务器路由、全部网页模块及现有检查/测试/CI；仓库中没有额外 AGENTS.md，遵守工作区禁止本地编译的约定。

原界面的问题：浮动底部切换器占用内容区；标题和表格留白较大；浅绿色颜色散落在多个文件；没有深色主题；首次看到大量原始表格；跟踪订单缺少快速搜索；汇总盈亏转 Number 并截断至四位小数。来源搜索与失败筛选、缓存错误提示和真实执行遥测可以保留。

选择继续使用原生 ES modules，而非引入 React/Vite：首轮不需要复杂前端路由，现有表格与服务边界清晰；保留零构建的分发方式，避免为新增概览改变资源发布链。新增 `overview.js` 是可独立测试的只读投影，`theme.js` 管理外观偏好；共享 CSS 作为统一的组件基础。这是首轮选型，后续页面可以在方向确认后单独评估框架迁移。

## 设计基础

`style.css` 定义语义颜色（背景、表面、文字、边框、交互、选中、成功、警告、错误、信息、禁用、焦点和遮罩）、4px 间距、三档圆角、阴影和动效 token。浅色使用中性灰和蓝色操作强调，深色使用分层灰。主题跟随系统或手动选择；偏好只保存浏览器 localStorage，存储不可用时仍能切换；外部脚本在 CSS 前执行，遵守现有 CSP。

共享组件基础覆盖 primary/secondary Button、Input、Select、results Surface、Badge、Table、Notice、Pagination、Disclosure。使用原生控件及语义 HTML，无第三方依赖。现有业务没有 Dialog，本轮不为展示组件完整度增加无用弹窗；后续真正需要危险操作时，必须按现有业务安全规则实现确认和焦点管理。

桌面概览为订单监控和执行状态双栏；1280px 以下合并为单栏；768px 以下指标为两列。表格独立横向滚动，不删除字段，窄屏不隐藏操作。顶部导航、跳转链接和 section links 缩短路径。执行图按面板宽度切换布局，展开后仍可阅读。

数字采用 tabular-nums，速览数量和价格右对齐、ID/金额不做浮点转换。盈亏同时有文字标题、正负号和颜色。原始状态码始终有文字，不臆测后端未定义的状态名称。普通控件按下反馈 120ms，执行完成反馈 180ms；不对价格和盈亏更新做动画。减少动态效果时关闭 CSS 动画和启动层；执行模块保留已有减少动态效果检测。

## 验收与剩余工作

新增纯 JavaScript 回归测试覆盖大整数和高精度小数、状态 5、未知状态、搜索/筛选、时间排序、页码收紧、空列表、盈亏正负号及存储不可用时的主题切换。`npm run check` 静态验证语法、DOM ID、模块导入、Qt 资源和服务器白名单；`npm test` 只执行 JavaScript 模拟测试，不访问生产接口，不编译。远端原有 Build and release CI 执行原生测试和各平台发布包检查，新增资源纳入发布检查。

Phase 4 的完整业务页面迁移须等设计方向确认。Phase 5 的全部业务回归仍在后续阶段。本轮未改交易策略、配置语义、鉴权、HTTP API 或数据库。WCAG 2.2 AA 是审查目标，不把静态检查当作完整合规认证。实际 Qt WebEngine、真实手机触摸/键盘/安全区域、屏幕阅读器以及真实长时间高频快照仍需实机验收。

## 动效复查与已执行检查

参考 `apple-design`、`emil-design-eng`、`mobile-native` 和 `review-animations`。没有引入复杂新动画，不需要额外调用 animate；没有增加 break-ui 的演示数据开关，使用隔离的浏览器假数据测试覆盖长文本和极端数字，不把演示数据带入交易页面。

| Before | After | Why |
| --- | --- | --- |
| flow.js 请求结束时执行 450ms stroke 闪动 | 删除 acknowledge 闪动；依旧通过请求计数、状态和最近事件反馈 | 高频请求不需要重复描边动画，避免 SVG 重绘及历史完成反馈干扰 |
| 底部导航滑块位移 | 顶部标签静态选中背景 | 高频与键盘导航即时响应，减少视线移动 |
| startup.js 淡出背景写死浅绿色 | 使用启动层当前计算背景色 | 深色启动时不闪回浅色 |

动效复查结论：本轮新控件和导航可接受；保留真实活动连接的原有请求期间运动及减少动态效果分支，不新增价格动画。原有桌面 logo 启动过渡仍属旧实现，实机表现和性能需后续确认，不声称完成全站动效验收。
