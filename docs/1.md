可以.数据读取到了大部分.还有1部分:close_price 需要我自己做个运算
我用close_price的计算公式进行计算:
第一步:判断方向。size 是 -37,小于 0,是空单,所以 Value 取 -value,也就是 -344.2961。分母不是 0,可以继续算。
第二步:保证金乘以 3.1。4.852279702667 乘以 3.1,等于 15.04206708(约数)。
第三步:除以 Value。15.04206708 除以 -344.2961,约等于 -0.043689。也就是变动比例约为 -4.37%,负号是因为空单的 Value 取了负数。
第四步:算 1 加上这个比例。1 + (-0.043689) = 0.956311。
第五步:乘以开仓价。88.077351351351 乘以 0.956311,约等于 84.2293。
第六步:对齐步长。mark_price 是 93.053,小数点后 3 位,所以步长是 0.001。把 84.2293 保留 3 位小数,得到 84.229。
最终结果:close_price = 84.229
